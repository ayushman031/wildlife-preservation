# 🐾 Wildlife Conservation India - Complete Website

A comprehensive, professional 6-page wildlife conservation website built with **HTML, CSS (Bootstrap), and JavaScript** focused on protecting India's rich biodiversity.

## 📋 Project Overview

**Wildlife Conservation India** is a fully responsive, feature-rich website dedicated to wildlife conservation in India. Perfect for college/university assignments showcasing modern web development practices.

**Theme:** Wildlife Conservation in India  
**Pages:** 6 Complete Pages  
**Framework:** Bootstrap 5.3.2  
**Fonts:** Google Fonts - Roboto  
**Icons:** Font Awesome 6.4.0  
**Color Scheme:** Professional Green & Brown (3-color palette)

## 🚀 How to Use

### **Method 1: Direct Opening**
1. Download all files maintaining folder structure
2. Keep `css/` and `js/` folders intact
3. Open `index.html` in any modern browser
4. Navigate between pages using header menu

### **Method 2: Live Server (Recommended)**
1. Install VS Code + Live Server extension
2. Open project folder in VS Code
3. Right-click `index.html` → "Open with Live Server"
4. Website opens at `localhost:5500`

### **Method 3: Deploy Online**
- **GitHub Pages:** Push to GitHub, enable Pages
- **Netlify:** Drag & drop project folder
- **Vercel:** Deploy via CLI or web interface
